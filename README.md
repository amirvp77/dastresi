# 🛍️ دسترسی | فروشگاه اینترنتی Dastresi

یک فروشگاه اینترنتی طراحی‌شده با React که محصولات، تخفیف‌های روزانه، برندهای محبوب و کالاهای جدید را در یک رابط کاربری واکنش‌گرا نمایش می‌دهد.

## 🔗 لینک‌های پروژه

- **مشاهده سایت:** [Dastresi Online Shop](https://dastresi-nine.vercel.app/)
- **دیتابیس JSON:** [مشاهده db.json](https://amirvp77.github.io/dastresi-db/db.json)
- **مخزن اصلی پروژه:** [GitHub Repository](https://github.com/amirvp77/dastresi)
- **مخزن دیتابیس:** [Dastresi Database](https://github.com/amirvp77/dastresi-db)

## ✨ امکانات پروژه

- نمایش محصولات فروشگاه
- نمایش تخفیف‌های روزانه
- نمایش محصولات جدید
- نمایش برندهای محبوب
- اسلایدر تصاویر و محصولات با استفاده از Swiper
- تایمر شمارش معکوس تخفیف‌ها
- طراحی واکنش‌گرا برای موبایل و دسکتاپ
- دریافت اطلاعات محصولات از طریق Fetch API
- مدیریت وضعیت بارگذاری و خطا در دریافت اطلاعات

## 🛠️ تکنولوژی‌های استفاده‌شده

- React
- JavaScript
- Vite
- Tailwind CSS
- Fetch API
- Async/Await
- React Hooks (`useState` و `useEffect`)
- Swiper
- JSON

## 🚀 اجرای پروژه روی سیستم شخصی

### ۱. دریافت پروژه

```bash
git clone https://github.com/amirvp77/dastresi.git
```

### ۲. ورود به پوشه پروژه

```bash
cd dastresi
```

### ۳. نصب وابستگی‌ها

```bash
npm install
```

### ۴. اجرای پروژه

```bash
npm run dev
```

پس از اجرا، آدرس محلی نمایش‌داده‌شده در ترمینال را در مرورگر باز کنید.
